## 设计与验证

- 工作台完整导航；业务域使用 64 px 图标轨和可收起的上下文菜单。问题台账作为进入多个问题的入口。
- 独立工作页使用轻量标签元数据，重复记录去重；单工作页隐藏标签条，多页 36 px 单行；根据宽度保留当前及最近标签，其余进入全部已打开面板。
- 标签元数据在当前浏览器会话中恢复；只渲染活动页面。少量演示草稿驻留内存，切换不丢失；关闭未保存问题需明确确认。浏览器刷新不保存演示正文。
- 支持新浏览器页签打开。URL 包含页面与记录标识，离线版使用哈希。
- 主题偏好单独保存，存储不可用时正常运行。浅蓝默认；Ant Design 和自定义 CSS/SVG 均使用主题变量。状态色保持固定语义。
- 专注模式隐藏领域导航、业务菜单及右侧上下文，保留流程节点和正文。
- 验证：类型检查、离线打包、真实浏览器中的多标签去重/关闭/溢出/恢复/草稿保护、三种主色与深浅模式、窄屏。保留既有 file URL 浏览器策略限制，不声称离线运行实测。
