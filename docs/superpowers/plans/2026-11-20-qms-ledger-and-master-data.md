## 上线验证

- 工序主数据迁移保留原工序板块规则的表、唯一约束和写入语义。真实 PostgreSQL 回归运行了原 API 的旧写入语句，确认新迁移后仍可写入。
- 有编码的工序使用独立记录，旧规则补录编码时事务内转入并保留 ID。启用 IMS 规则前，可先为已核实的旧规则补录编码。同名候选不唯一时无编码历史记录待人工确认。
- 发布后确认新 API 和 Worker 就绪，再启用工序入库。回滚到不支持 `OPERATION` 的版本前，在当前版本停用规则并处理工序目标下所有自动、单条及历史任务。旧版本暂停展示按编码管理的新工序资料。生产回滚和正式 IMS 报文验收尚未执行。
