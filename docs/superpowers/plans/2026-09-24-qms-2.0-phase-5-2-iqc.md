# QMS 2.0 阶段五 5.2 IQC 来料检验实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `superpowers-zh:subagent-driven-development` 或 `superpowers-zh:executing-plans` 逐任务实现。步骤使用复选框跟踪进度。未经用户要求不得提交、推送或合并。

**目标：** 交付组织隔离的 IQC 来料检验、重点物料照片存档、NG 到供应商问题的显式关联，以及未启用的 MES 批次/结果适配器契约。

**架构：** 独立 `supplier-incoming` 领域持有检验事实、来源快照及照片引用；现有供应商资料校验组织关系，现有文件服务负责对象存储和扫描，现有供应商问题与 Workflow 负责整改。MES 未具备真实契约与样本前保持未启用。

**技术栈：** NestJS、Prisma、PostgreSQL、Swagger/`@qms/contracts`、React、对象存储、扫描 Worker、Playwright。

**当前交付记录（2026-09-24）：** 已完成迁移、规则/DTO/服务/Controller、照片资源适配器、MES 未启用端口、权限目录、seed、模块接线和内部 IQC 页面；API lint/build、Web lint/build、契约检查、治理检查、API 单元测试（39 套、444 用例）及 API/Web 专项测试通过；一次性 PostgreSQL 全量迁移和本地 seed 通过。真实对象存储/扫描、HTTP 主链、浏览器联合验收及 MES 联调仍按下方任务执行。
