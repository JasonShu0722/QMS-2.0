# 阶段五 E1 试产总结原生报告实施计划

> **面向 AI 代理的工作者：** 使用 `superpowers-zh:test-driven-development` 逐项先红灯后绿灯；完成后进行规格、质量和真实资源验证。

**目标：** 从已批准且来源未过时的试产总结下载原生 XLSX/PDF。

**架构：** 现有 Service 在同一只读事务内核对权限、组织、批准状态、版本与实时来源 SHA-256，再将受控快照交给独立渲染器。Controller 发送二进制响应；Web 通过受保护下载端点取得 Blob。

**技术栈：** NestJS、Prisma、PostgreSQL、ExcelJS、PDFKit、Noto Sans SC、React。

- `qms-2.0/apps/api/src/modules/new-product-quality/trial-summary-report.ts`：受控快照转 XLSX/PDF。
- `qms-2.0/apps/api/src/modules/new-product-quality/new-product-quality.service.ts`：下载授权和来源核验。
- `qms-2.0/apps/api/src/modules/new-product-quality/new-product-quality.controller.ts`：二进制 HTTP 响应。
