## 验证与交付

每个写集先执行失败用例，再实现并跑通过用例及邻近回归。冻结源码后检查受影响的 Web、API、共享契约、真实 PostgreSQL 与附件扫描链路、生产构建、治理和 `git diff --check`。用真实浏览器覆盖各类入口角色、桌面和窄屏、日期及滚动、草稿重开、附件、正式提交、授权窗口与实际 PDF。记录环境、命令、结果及未验证条件。先做独立规格审查，再做质量审查，返修后复验。

全部适用门禁通过后按版本规则形成一条 PR，关联所有 Issue，核对 PR 最新提交与当前基线的检查后合并。合并后核查主分支检查、部署及最终业务验收状态，按授权逐项关闭并回读。回滚以本批 PR 为边界，旧快照和存量内容继续可读。项目级交互规范与覆盖清单随实现更新。
