# F4 客户与二方审核 Excel 导入实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `superpowers:subagent-driven-development`。

**目标：** 为审核管理接入受限真实 XLSX 解析、逐行预览、错误反馈和可安全重试的导入界面。

**架构：** Web 解析 XLSX 并校验行；每个有效行调用既有审核导入 API，使用稳定幂等键。权限和唯一性仍由 API 服务端决定。

**技术栈：** React、Ant Design、ExcelJS、Vitest、生成 OpenAPI 契约。
