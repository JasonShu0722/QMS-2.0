# QMS 2.0 阶段五 D2 客户投诉处理实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `superpowers-zh:subagent-driven-development` 或 `superpowers-zh:executing-plans` 逐任务实现此计划。步骤使用复选框（`- [ ]`）跟踪。按项目 `qms-superpowers-zh` 执行 TDD、两轮审查及真实资源验收。

**目标：** 在现有客诉台账上交付人工登记、分类、责任部门/经办人、可追溯进展、解决、独立复核关闭与归档，并与既有正式问题 Workflow/8D 关闭互锁。

**架构：** `customer_quality_complaints` 保存当前状态，新增不可变事件保存处理历史；客诉服务只控制台账处理，正式问题仍由 `CustomerIssueService`、问题索引和 Workflow 管理。所有写操作复用组织权限、幂等、CAS、审计、文件授权和扫描服务。

**技术栈：** PostgreSQL 18、Prisma、NestJS、Swagger generated contracts、React/Ant Design、Vitest、Jest、Playwright、MinIO、ClamAV、Worker。

**设计规格：** [D2 客户投诉处理设计](../specs/2026-09-26-qms-2.0-phase-5-d2-customer-complaint-design.md)。开始实现前再次读取根及 `qms-2.0/`、`apps/api/`、`apps/web/` 的 `AGENTS.md`，并检查当前未提交变更；只在 `D:\WorkSpace\QMS-2.0\qms-2.0` 实现，不修改已执行迁移。
