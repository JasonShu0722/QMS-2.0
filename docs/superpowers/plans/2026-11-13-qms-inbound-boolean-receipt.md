## 规格与影响

成功接收且 returnReceipt=true：HTTP 200、application/json、正文为 JSON 布尔字面量 true（不是字符串、不是对象）。returnReceipt=false：HTTP 200 空正文。仅接收事务成功提交后返回成功；失败仍按既有 4xx/5xx 和错误对象响应。内部 receiptId/messageId/receivedAt/status、持久化、检索、审计与非关键观测保持原有语义。依赖旧回执对象的调用方须改用布尔成功判断；管理端继续检索内部编号，X-Request-Id 继续用于排查。

Controller HTTP 适配、Swagger 生成契约、Web 中英文调用说明和剪贴板配置、真实 PostgreSQL 接收/观测/删除/保留测试与既有 Playwright 消费路径必须同时覆盖。服务层不为布尔响应丢弃内部事实，不引入兼容开关或新包装。
