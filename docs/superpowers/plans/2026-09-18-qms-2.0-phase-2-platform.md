# QMS 2.0 批次 2：问题与流程平台实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在批次 1 底座之上完成可真实创建、流转、查询、追溯和恢复的问题与流程平台，并通过统一批次验收。

**架构：** 保持 NestJS 模块化单体、React 前端、PostgreSQL 18、Prisma 7、REST/OpenAPI 和 PostgreSQL Outbox/Worker。领域模块拥有问题事实，`problem-index` 只拥有跨域索引；`workflow` 拥有受控定义和运行实例；`task-notification` 通过公开服务消费事件；前端通过生成的 `@qms/contracts` 调用 API。

**技术栈：** React 19、TypeScript、Vite、Ant Design 6、TanStack Query、Zustand、React Flow、NestJS 11、Prisma 7、PostgreSQL 18、Vitest、Jest、Supertest、Playwright、pnpm 11.19.0。
