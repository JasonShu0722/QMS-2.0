# A2 Worker、提醒与升级可观测性实施计划

## 目标

在不复制通知通道和不改变提醒/升级业务规则的前提下，为真实 Worker 增加可选的周期结果观测，并保留真实 PostgreSQL 与编译进程证据。

## 步骤

- [x] 核对现有 Workflow timing、Outbox 租约/重试和 Worker 进程测试。
- [x] 为 runner 增加可选周期观察器及稳定的结果字段。
- [x] 增加 `QMS_WORKER_LOG_CYCLES` 受控日志开关和非法配置拒绝。
- [x] 增加 runner 单测与真实编译 Worker `--once` 日志解析测试。
- [ ] 在阶段五整体验收中使用一次性 PostgreSQL、真实 Worker 和日志采集环境复核告警接线；本计划不提前宣称该项完成。

## 文件边界

- 实现：`apps/api/src/worker-runner.ts`、`apps/api/src/worker.ts`
- 测试：`apps/api/test/task-notification/worker-runner.spec.ts`、`worker-process-schema.integration-spec.ts`
- 文档：本规格与计划、`docs/README.md`、`governance/documentation-index.json`

## 回滚

删除 `QMS_WORKER_LOG_CYCLES` 环境变量即可关闭运行观测；无数据库迁移和数据回滚步骤。
