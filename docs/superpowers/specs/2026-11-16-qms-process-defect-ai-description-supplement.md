## 推荐的最小能力

### 已明确的本次描述行为

负责人追加明确：不良描述提示词聚合多个IMS字段；模型出错默认罗列配置字段，模型成功则直接在不良描述显示生成结果。因此使用同一个现有不良描述展示位，不另让用户只在独立AI面板查结果：先保存直接罗列文本作为保底，异步结果有效后替换展示；失败、超时、空输出或响应无效均继续显示保底，不阻断台账。后台保留来源及两类结果以供追溯。此前人工优先决定继续有效，生成期间人工已修订时，迟到AI结果仅作建议，明确采用后才覆盖。

### 1. 组织内AI连接配置

在管理界面提供AI渠道列表/新增/编辑：名称、服务API地址、允许模型列表、默认模型、密钥、启停、连接测试结果。首版支持OpenAI兼容协议；具体服务及数据可发送范围在启用时核定。支持多份具名渠道，每渠道的密钥独立加密保存；同一渠道支持多个模型，入库规则先选渠道再选其允许模型，不按模型复制密钥。有效platform:admin默认开放，其他内部人员按既有配置管理/使用权限授权。

这里配置的是访问模型服务的密钥，与IMS调用QMS的接收机器凭据、IMS来源明细编号分别管理，互不替代。

连接暂按组织内授权共用、密钥不随人员展示设计：有权人员能新增或替换，普通使用者只能选已授权连接并用于受限描述任务，不能借调用入口发送任意请求、试探密钥或转发任意正文。跨组织不列出或引用连接。没有查看密钥原文的权限或API操作，管理员也无界面/接口回读原文入口；服务器运维和根加密密钥仍按既有系统运维边界管理，不承诺服务器root无法取得运行时秘密。

### 2. 密钥只写不可回读

- 输入密码框默认遮罩，不提供明文切换/复制按钮；添加时人员填写自己取得的密钥，成功后清除前端输入。
- 保存/详情/列表/测试响应仅含hasKey等状态和安全元数据，不含原文、可解密密文或密钥片段。本人保存后也不能从系统取回。
- 服务端加密存储，只有获准服务调用路径在内存解密；不放入浏览器持久存储、提示词、业务正文、普通日志、审计、错误响应或导出。
- 新密钥密文纳入既有keyring轮换、重加密及备份恢复覆盖；恢复后默认核对连接启停和授权，再决定是否恢复外部调用，不另建一套主加密密钥配置。
- 编辑时不回填密钥。留空表示保留原值，替换需要填写新值；清除是独立明确确认，不能误把留空当删除。
- 密钥与服务地址绑定。改变地址必须重新输入密钥，不能把已有密钥带到新服务；地址严格校验HTTPS/允许目标、拒绝内网及重定向绕转，避免利用测试/调用提取其他人的凭据。
- 连接测试返回受控成功/失败原因，不透传供应商原始错误、Authorization头或请求对象。审计记录添加/替换/清除/启停的操作者、时间、配置ID与版本，密钥不进入响应或通用审计。

### 3. 入库规则中的描述方式与提示词

继续复用当前多字段选择、顺序和标签，增加可选“AI整理”，保留“直接组合”作为默认及回退。配置选择AI连接、编辑提示词、单条试运行；预览并排展示原始选定字段、直接组合文本及AI结果，保存提示词版本，不把其他台账或完整接收正文自动发给模型。

输入配置逐项选择源字段路径、显示标签、变量名及顺序，可从已有直接组合字段复用后调整；仅这些选定输入发送模型。提示词支持`{{变量名}}`，引用必须存在且变量名不重复，不执行模板代码。渠道、模型、提示词、输入和输出设置随规则版本冻结。

输出配置支持纯文本或JSON指定字段。JSON模式填写输出字段名，例如`defectDescription`，服务端只接纳该字段的有界非空字符串，其他内容不写台账；纯文本直接采用有界文本。两种模式均映射到本阶段明确支持的QMS“不良描述”，不开放模型任意修改编码、数量、项目或人员。解析/校验失败仍显示直接组合文本。未来其他业务输出需对应明确领域写入规则，本期不引入通用工作流平台。

系统固定约束与可编辑业务提示词分开：选定字段作为数据，不作为模型指令；仅汇总已给事实，未知不编造，不推断原因/责任，不改编码/数量/日期等其他业务字段。模型结果限定为有界纯文本描述，进行响应结构、长度和内容展示校验；不执行HTML、工具调用或模型返回的业务动作。提示词不能访问服务器密钥或环境。

### 4. 入库后的异步整理

```text
接收对象数组 → 原有有序入库 → 保存直接组合描述及来源
                                ↓
                        独立AI描述待处理任务
                                ↓
                 调用获准连接及固定提示词版本
                                ↓
             校验结果 → 未被人工改过则采用，否则作为建议
```

复用Worker调度，AI网络调用放数据库事务之外：先短事务认领任务，再调用，最后检查任务/来源/描述版本后短事务保存结果。不能让一次AI超时卡住后续不良入库或长时间持有台账/组织锁。设置有界并发、超时及有限重试，失败保留原文和状态，可人工重试；不保证网络未知结果下外部服务只计费一次。

同一入库结果和输入/提示词版本不重复生成同一任务；提示词或输入改变后需要新版本任务。旧结果到达时若输入已更新则不覆盖新描述。保留原始选定事实、直接组合结果、AI结果及采用来源；人工描述优先，后续AI只能提供建议，用户明确采用才改变人工结果。不得因项目/板块自动补配这种无关版本变化误删原描述。

## 验收与当前未决边界

业务配置与密钥管理分开验证：不同人员可按权限添加，任何读取/测试/导出API均不返回密钥，换地址不复用旧密钥，普通使用权限不能任意外发；只发所选字段，失败/超时/重试不阻塞台账；人工修改、输入更新、旧结果迟到及重复任务均有实际回归；提示词版本及采用历史可追踪。真实模型验收使用上线获准的服务和测试资料，不能用模拟响应冒充真实连通。

本补充已批准作为REQ-0038同一PR交付。模型成功直接展示、失败罗列保底和密钥不可回读为已明确口径，不再重复询问。具体真实密钥/服务与数据授权属于后续启用配置，不需要在聊天里提供密钥原文。真实供应商联调和物理手机未执行时记NOT_RUN，不以本地受控HTTP测试冒充供应商验证。

## 2026-11-18 需求澄清：API来源字段与提示词变量绑定

负责人明确：制程不良由 API 入库触发，提示词变量必须能够使用 API 报文中的来源字段，不能让用户在 AI 区域重复维护一套脱离入库规则的来源路径。本节将此前的“AI输入字段单独配置”收敛为以下正式口径。

### 配置关系

- “不良描述来源”选择“多字段组合”时，字段数量由规则编辑者按实际报文灵活增加、删除和排序。
- 每个组合字段配置 API 报文来源路径、直接组合描述标签和变量绑定。变量绑定属于 API 入库规则，明确哪个 API 字段作为哪个变量的输入事实。
- 提示词应用只负责定义可供提示词调用的变量和提示词正文；提示词正文使用这些变量，例如 `{{fault}}`、`{{position}}`。它不再单独维护另一套 IMS 来源路径。
- 选择提示词应用和已发布版本后，API 规则的多字段组合行从该版本的变量集合中选择变量；同一变量不能绑定多个 API 字段。
- 启用 AI 时，提示词正文实际引用的变量必须能在多字段组合中找到来源绑定；未被正文引用的应用变量不强制配置来源。
- AI 整理区域只选择提示词应用和已发布版本，不再另填一套独立的 IMS 来源路径。

示例：

```text
API 报文字段       提示词变量       直接组合标签
WP_NAME            fault            不良现象
LB_ID              position         发生位置
OP_NAME            operation        工序
```

提示词应用提供可调用变量：

```text
fault      不良现象
position   发生位置
operation  工序
```

提示词中使用 `{{fault}}`、`{{position}}`、`{{operation}}`。规则运行时先按多字段组合提取 API 值，生成直接组合保底文本，再用同一批已提取值按变量绑定渲染提示词并异步调用 AI。规则快照继续保存 `descriptionComposition.fields` 与 `aiApplication.inputFields`，其中 `aiApplication.inputFields` 是多字段组合来源路径到变量的绑定快照，两者的来源路径必须保持一致；不新增表或迁移。

### 提示词应用编辑体验

提示词应用编辑器在变量编辑区展示当前可供调用的变量名和变量标签，并在提示词输入框旁提示“可使用 `{{变量名}}` 引用输入变量”。点击变量时，在当前光标位置插入对应占位符；服务端仍以变量白名单校验为最终依据。变量删除或改名时，提示词中遗留的占位符必须在保存校验中被拒绝，不自动改写已发布版本。

### 缺失与兼容

- API 来源字段缺失或值为空时，不能把未替换的 `{{变量名}}` 发给模型；该次 AI 整理失败或跳过，保留直接组合结果。
- 直接组合字段是 API 规则的事实来源；只有提示词正文实际引用的变量必须完成 API 字段绑定，未被正文引用的应用变量可以暂不绑定。
- 已有规则加载时保留原 `inputFields`；编辑界面将其映射为“组合字段行→提示词变量”，不得静默改变历史规则快照。
- 已发布提示词版本不可变，历史任务继续使用原规则快照；修改 API 来源路径或切换提示词版本必须显式保存规则后才影响新入库任务。

### 暂不扩展

本次不引入通用模板引擎、任意脚本、自动推断 API 字段、跨业务变量共享、模型自动切换或新的数据库结构。上述内容为需求归档与实现边界，尚未启动本轮代码修改。
