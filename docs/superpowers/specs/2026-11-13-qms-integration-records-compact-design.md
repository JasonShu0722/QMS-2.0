# 接收记录操作与管理顶部密度调整

日期：2026-11-13。负责人已认可整体方案并要求启动落地；REQ0036 / Issue97，V0.0.50。本次是一期使用体验追加，不涉及二期业务映射。

## 页面行为

移除接收记录页最近清理成功及失败时间展示及其占位，不增加存储详情入口；后台保留清理任务、内部运行事实和审计。正文容量与视图选择、刷新记录、筛选条件合为同一操作栏，仍可按权限点击设置。容量读取失败按当前状态提示，不因删去历史清理时间隐藏当前读取失败。

列设置与分页共处表格上方一行；总数、每页条数、前后页、当前/总页数和跳页紧凑呈现，默认20，提供10/20/50/100/500/1000。记录查询API最大1000，接口候选和其他管理分页不扩大。只加载元数据，正文仍在详情中按权限读取。切换条数/筛选回第一页；删除后页码超出范围回到最后有效页。分页区域在列表上方保持可达，窄屏自然换行；不叠加一套底部分页。

选择仅属于当前页。切页、条数、筛选、视图、组织或身份变化时清空；加载下一页期间不保留旧行可删选择。有选择才出现底部固定浮动操作条：已选数量、取消选择、删除所选；单条删除仍保留。操作条不遮住末行、反馈入口或窄屏控件，确认弹窗位于其上方。删除最多1000条，复用原管理授权、近期认证、CSRF、幂等、事务、审计和容量扣减。提交及未知结果阶段冻结相关操作，未知结果沿原请求重试；不能换选择创建第二个不确定请求。成功更新总数、容量和选择，不跨页全选结果集。

管理端公共内容容器到首个页签/标题/工具栏的顶部间距统一12～16px，排查页面额外首项边距及嵌套容器；不压缩字号/控件点击区域，不改业务端与供应商门户，不隐藏真实标题或状态警告。桌面、窄屏、现有主题和语言都须兼容。
