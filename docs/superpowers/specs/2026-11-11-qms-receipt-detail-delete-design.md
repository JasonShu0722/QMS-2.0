# 接收记录详情与删除体验设计

2026-11-11负责人确认一期继续优化接收记录：详情默认展开正文、正文框内滚动、框内复制按钮、列表多选及删除记录。本设计只覆盖接收记录使用体验，不扩展业务字段映射、异步业务处理或发出接口。

同一批次追加三个管理页体验要求：去掉公共管理页冗余身份/资源说明区；筛选默认收起并与刷新并排；接收记录直接展示接口名称。三项横展到管理页面时保留权限、组织切换、键盘可用性和当前数据请求行为。

## 1. 详情阅读

- 打开接收详情后，具有 `integration:payload:read` 且正文仍可用时自动读取正文；不再要求点击“查看接收正文”。读取失败保留详情并显示局部重试。
- 正文使用固定最大高度和 `overflow:auto`，长行换行；弹窗本身保持可视区域，标题和关闭按钮不随正文滚动。
- 正文框右上角提供固定复制按钮，复制完整原文；成功/失败显示局部反馈。仍使用现有纯文本 `<pre>`，不执行 HTML/脚本。
- 无正文权限、正文已清理或详情请求失败时不读取、不显示复制按钮；现有组织范围、ABA、审计和缓存控制保持。

## 2. 记录选择与删除

- 接收记录视图首列增加 checkbox；支持逐条选择、当前页全选/取消全选。切换视图、筛选、分页或组织范围时清空选择；不做跨页“全选所有筛选结果”。
- 当前页有选择时显示已选数量和“删除所选”；每行提供单条删除，单条删除复用相同确认流程。
- 删除操作复用现有 `integration:manage` 权限、CSRF、近期认证和 `AdminMutationService` 幂等保护；没有该权限不显示删除入口，服务端仍拒绝越权。
- 服务端接口：`DELETE /api/v1/admin/integrations/receipts`，请求 `{ organizationId, receiptIds: string[] }`；数量1～100，空数组/重复/非UUID拒绝400。返回删除数量和实际删除编号。
- 事务按组织→接口→收件记录顺序加锁；只删除当前组织、元数据仍在保留期的收件记录。每条记录释放仍存在的密文字节，精确更新接口及组织容量；正文已清理的记录释放0字节。请求结果表保留，`receipt_id` 仅作为可空检索标识；删除审计按收件编号记录。
- 删除不可恢复，不影响接口、凭据或后续接收。删除后刷新列表和容量事实，清空选择；当前页删空时回到上一有效页。

## 3. 验收边界

- API 真实 PostgreSQL 覆盖成功/越权/跨组织/空重复UUID/批量上限/并发清理锁、容量释放、审计失败回滚、幂等重放及请求结果保留。
- Web 覆盖默认正文读取、权限/到期边界、框内滚动/复制反馈、选择/全选/切页清空、单条/批量确认、删除后刷新和无权限隐藏。
- 不新增数据库迁移；不修改外部收件协议、数组规则、凭据、接口删除或发出接口。完整发布沿 Issue97 / V0.0.47 及现有 PR/main/deploy 流程。

## 4. 公共管理页体验

- `ConsoleLayout` 删除正文内重复页标题及身份/资源范围说明区，覆盖全部管理路由；沿顶栏面包屑保留页面定位，目标组织选择器移到顶栏紧凑位置。SESSION_HOME使用所属组织、不提供错误的目标切换。保留键盘标题焦点、组织切换的未保存保护和全部context/权限校验，不因清理展示删除安全逻辑。
- `ReceiptList` 筛选默认收起；“筛选”按钮和“刷新记录”并排，展开后保留现有表单、校验、筛选请求和切换清空逻辑。重新打开页面默认收起。
- 接收记录和请求结果的来源/接口列直接展示接口名称，接口编码作为次级辅助信息保留，详情同样优先名称。筛选入口按名称搜索/选择接口，服务端查询仍以选中接口UUID约束；接口名称选项由收件读取权限控制的接口候选查询提供，包含保留历史的已删除接口，不要求配置读取权限，不逐行补请求。
