## A：统一紧凑规范（REQ-0021）

以共享密度变量统一页面边距、区块间距、卡片与表格内边距：桌面页面 16 px，中间宽度及手机 12 px，区块 12 px，卡片 16 px，表格单元格上下 8 px。保留 36 px 标准控件、触屏高频操作约 44 px 点击区域；文本、错误与业务表单不得为压缩高度被截断。空态不增加装饰性大间距，普通空态内边距不超过 24 px。

主题层桥接 Ant Design，外壳、工作台及正式模块消费变量。横展检查页面标题、辅助说明、台账、表单、弹窗；删除向用户暴露实现细节的说明，保留必要权限、失败、未保存、导入规则与安全提醒。六主题、中英文、双门户和三档宽度沿既有验收规则。复用共享变量，不增加密度切换设置或检查框架。

## B：个人账号完整交互（REQ-0017/0018）

顶栏顺序为公告、EN/CN 语言、外观、最右头像；语言偏好沿现有机制，登录页共享语言下拉不变。修改密码从头像菜单在当前页打开紧凑弹窗，复用现有改密 API；成功撤销其他会话，保留当前会话。提交时防重复与关闭，失败保输入，关闭清理秘密并归还焦点；有未提交输入时关闭确认。首登强制改密与 MFA 挑战保持。

账号页整合资料与安全状态，移除旧改密卡片和锚点逻辑。安全弹窗保留绑定、恢复码、邮箱确认；精简说明但保留邮箱用于自助找回的用途。个人菜单、安全弹窗和资料页入口保持一致，头像附件扫描和管理员集中 MFA 不变。

新增 `GET /api/v1/me/sessions/history`：仅完整本人认证、只读、不接受目标用户或组织参数。复用 sessions，稳定按创建时间与 ID 倒序分页，返回有限页及总量、登录/到期/撤销时间、期限类型、当前标识和有效/撤销/过期状态。分页参数经 DTO 验证并设置有界单页大小。只查询安全列，不返回摘要、密钥、令牌或其他用户。现有有效会话与撤销 API 不变，撤销后刷新历史。

与新建登录事件表相比，复用历史会话无需重新采集数据、迁移或设定新的删除期限；保留现有历史，不增加 IP/设备/失败登录采集。既有 userId 索引为本人查询基础，性能数据出现瓶颈再评估专用索引。

## C：主数据维护与连续导入（REQ-0019）

供应商、客户、物料按原领域事实、权限和组织范围维护；单条新增、批量导入改为弹窗，导航入口相邻。导入继续只新增、重复跳过、不覆盖已有关系；供应商导入不创建组织或账号。

采用前端顺序分块，消除用户侧固定 100 行总量限制；每请求仍遵守 100 行及请求体预算，独立幂等键，原全局行号贯穿结果。显示已处理/总量、成功/跳过/失败与逐行结果；失败保留当前块及键，可显式重试，不能猜测失败请求未提交。终止确认后在当前请求完成时停止，已完成数据保留；刷新/关闭与内部路由保护沿共享未保存机制。大文件仍受现有 ZIP/解压/公式/字节安全边界保护，不把“不限行数”解释成无资源限制。

相比后台导入任务，此方案复用当前 API 与逐行事务，无需新增文件、Worker、任务表或权限。后台断点续传不在本次范围。

## D：审计可读性与紧凑查询（REQ-0020）

筛选与导出合并为紧凑工具栏，桌面常用控件一至两行，低频项可展开，手机可换行且不整页溢出。增加动作中文说明与操作人摘要，保留原动作码供追溯；未知动作回退原码。

操作人摘要由服务端从当前审计允许的组织范围内安全组装，使用用户名、账号类型和组织名，不新建姓名字段或修改历史审计。删除/系统账号使用明确占位，不因跨组织关联泄露未授权资料。CSV 同步中文动作与账号列，保留 5000 条限制、公式注入保护、快照查询与仅创建者下载。账号定位链接只有具备目标组织 `account:users:read` 时显示且后端再次授权。
