删除欢迎词、营销口号、泛化功能介绍、重复标题含义的副标题、页面设计意图、模块存在意义及实现原理。对用户任务无帮助的技术标识和调试说明不占正文，必要诊断信息进入受控详情。

删除文字时同步检查容器、卡片标题栏、嵌套、对齐和间距，去掉空占位，保留合理留白。不以缩小字号、触控目标或隐藏溢出追求紧凑，不增加虚构指标、说明或装饰卡片填补空白。

## 3. 业务导航：单列两级折叠菜单

参考：[21st.dev Multi-level Collapsible Menu](https://21st.dev/community/components/s/navigation-menu?preview=%2F%40cnippet-dev%2Fcomponents%2Fmulti-level-collapsible-menu)。仅借鉴缩进、箭头、展开与选中反馈，不搬示例卡片、固定颜色、演示数据或第二套组件库。公开源码只证明方案思路；动态预览及其键盘行为尚未实测。

将现有一级图标轨与二级上下文菜单合成一栏，仍保持“领域—页面”两级，不新增第三层。顶部工作标签保留。

```text
业务导航                 工作区
──────────────────┬────────────────────────────────────
 QMS        [收起] │ [个人账号 ×] [公告 ×]
                  │────────────────────────────────────
 ◇ 综合工作台     │                   [个人信息设置]
 ▸ 问题中心       │
 ▸ 供应商质量     │ [头像] 姓名       账号状态：启用
 ▸ 制程质量       │        账号       邮箱：未确认
 ……               │        所属组织   验证器：已绑定
 ▾ 系统服务       │
     公告         │ 登录会话
   ● 个人账号     │ 登录时间 │ 有效期至 │ 状态 │ 操作
──────────────────┴────────────────────────────────────
```

- 一级图标、名称与箭头清晰，二级缩进；当前页面、父级展开与悬停态不同。
- 父级点击只折叠，不意外跳转；原默认业务页保留为子入口。
- 选中由真实路由驱动，不照搬演示中的本地selectedId；标签切换、直链、刷新和详情访问正确定位并展开当前祖先，详情归属台账，不平铺新同级菜单。
- 建议默认展开当前领域，允许其他领域同时展开；宽度、行高、整栏收起形式和展开记忆在独立样例核对后冻结，不将建议当作已逐项批准。
- 760px及以下使用可关闭覆盖层；触屏目标至少44px；保留专注模式及退出、真实链接和另开、标签身份/会话隔离、dirty/busy保护。

## 4. 管理侧栏：分类与图标

保留工作空间、组织与授权、基础数据与配置、安全与运行等现有分组与真实能力过滤。分类通过字重、对比、组间距和对齐形成层级，不做成抢占视觉的大标题。

按业务语义替换多数入口统一回退的Settings：账号对应用户/凭证，档案对应企业/档案，物料对应物料/包装箱，映射对应关联，责任恢复对应恢复/历史，配置保留齿轮。复用lucide-react，统一尺寸与线条，相近业务可共享图标。

不改变console context、目标组织、SESSION_HOME/TARGET、PLATFORM范围、会话失效和401/403清敏；不把管理入口重新混入普通业务菜单。

## 5. 标题去重

业务页：侧栏和顶部标签保留入口/切换功能，正文删除重复页面名和无价值概览标题，操作并入信息区或紧凑工具栏。个人账号正文删除“个人账号”和“账号概览”，“登录会话”保留为独立分区。

不机械删除全部h1、详情对象名称、业务编号、编辑/新建上下文和内容分区。视觉去重同时保留可访问标题、主内容名称和可靠焦点；侧栏收起或窄屏时仍能识别当前页。

管理首页：删除正文“QMS / 管理工作空间”小字及重复面包屑，保留一处紧凑页头，组织选择和主要操作同行；窄屏自然换行。深层页面保留有返回价值的路径和对象标题。ConsoleLayout目前在范围/路由变更时聚焦heading，改标题必须维护焦点落点。

```text
管理首页                         管理组织 [智新控制 ▾]
──────────────────────────────────────────────────────
业务内容……
```

## 6. 主题与实现约束

业务系统维持浅蓝默认、蓝/青/紫品牌色、浅/深/跟随系统；控制台维持现行独立中性色和显示模式，不将其改成业务蓝色。保留各自偏好键、浮层与语言机制。

复用React、Ant Design、lucide-react、路由、工作标签、导航数据和主题变量。不新增UI库、字体、持续装饰动画、平行导航状态平台或后端菜单配置，不以安装外部Skill作为前置。
