# 物料主数据与制程不良台账视图优化

## 范围

- 物料主数据按组织服务端分页，支持物料编码/名称搜索、清空和当前筛选结果导出。
- 制程不良台账默认列顺序按录单核心字段排列；选择列、操作列固定显示；其他字段仍可在列设置中恢复。
- 台账行操作改为单行查看/删除图标，保留可访问名称和既有权限、删除预览、版本校验及未知结果恢复。

## 约束

- 不改变业务字段、删除语义、权限模型、数据迁移或生产数据。
- 保留已有用户列偏好；“恢复录单默认列”才应用新默认布局。
- 物料编码作为文本比较，保留大小写和前导零。
- 移动端允许表格内部横向滚动，页面不产生横向溢出。

## 验收

- 物料列表返回分页总数，搜索只作用于当前组织的编码和名称。
- 台账默认显示选择、发生时间、班次、项目号、细分类型、新品/量产、不良描述、追溯码、生产线名称、工序名称、板块、不良数量、操作。
- 操作按钮保持单行，图标按钮仍可通过可访问名称和键盘操作。
