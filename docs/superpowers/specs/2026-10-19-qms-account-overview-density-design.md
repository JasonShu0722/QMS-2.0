## 1. 单一登录会话清单

- 删除账号页面重复的活动会话列表和活动会话读取，保留一个“登录会话”表格。
- 复用生成契约中的历史分页接口，显示登录时间、失效时间、撤销时间、期限、有效／撤销／过期状态及当前会话标识。
- 仅有效且非当前会话允许调用原撤销接口。同步防重复提交、账号切换及卸载后的迟到响应保护继续有效。
- 表格区域内纵向滚动，窄屏在表格内横向滚动，表头固定；分页置于表格底部，保持在滚动体外。
- 撤销成功显示成功反馈并刷新历史；刷新失败提供只读重试，不重复撤销。改密事件刷新同一清单，不覆盖未保存邮箱。
- 保留加载、空、错误、分页和重试状态，加载／错误时不显示误导性的“暂无”。

## 2. 账号概览

- 基本信息与安全状态合为一张“账号概览”卡片。身份头像、账号名、所属组织和账号类型形成身份区，邮箱编辑与验证器状态／账号安全动作在同卡片内合理分区。
- 宽屏并列、窄屏叠放，长账号名和组织名可换行，不制造页面横向滚动。
- 头像与身份摘要同排，上传提示和控件置于其下，避免用户名被挤到上传控件之后而增加整张卡片高度。
- 保留头像编辑、邮箱校验及保存、原安全弹窗、关闭后焦点恢复、一次性秘密清理。安全状态只使用已有真实字段，不依据邮箱非空推断邮箱已确认。
- 参考 [Ant Design Pro 官方模板目录](https://github.com/ant-design/ant-design-pro)列出的 Account Center、Account Settings 和 Profile 分类，采用身份摘要与编辑／安全分区。沿用 QMS Ant Design、主题、图标和中文，不引入模板依赖或营销式装饰；目录检索不等同模板页面视觉实测。

## 3. 全部正式业务页面密度

- 共享页面 padding 从 16px 调为 8px，1200px 以下从 12px 调为 6px；区块 gap 从 12px 调为 6px，卡片 body padding 从 16px 调为 8px，表格单元格上下 padding 从 8px 调为 4px。
- 同步 Ant Design Card／Table token 和 CSS 变量，缩减卡片标题与内容的多余留白；正式页面中绕过共享 token 的区块、标题、表单间距逐项审视后收敛，避免只压账号页。
- 顶栏最小高度统一为 54px：桌面 36px 控件上下总留白从 36px 减至 18px；窄屏仍容纳 44px 按钮。显式 JSX Space／Row 间距、Typography 相邻标题和 Table 分页也按正式业务密度收敛。
- 保持 36px 标准控件与 44px 粗指针命中区域、正文可读性、权限、分页、状态及未保存保护。导航行、二维码、画布、登录品牌布局等非空白尺寸不机械减半。
- 深浅模式、三种品牌色、内部／供应商外壳及窄屏都沿用原机制。不修改设计原型、API、数据库、权限或业务语义。
