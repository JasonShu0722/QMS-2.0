### 0.2 通用约束（全清单引用，不逐域重复）

- G1 授权：岗位即业务角色，以有效任职、功能权限、数据范围、本单职责及状态 / 版本共同校验；按稳定 ID 关联，不按姓名、岗位名称或 admin 字符串放行。兼容直接授权保留来源，不自动合并、删除或迁移。
- G2 事实与历史：来源台账、正式问题、专业任务和引用关系分开；原文、当前采用值、提交快照及历史审批可追溯。更正 / 关联 / 项目阶段变化不静默改写旧批准依据。
- G3 数量：线索条数、客诉登记件数、追溯码数、正式问题数及供应商责任量分开；多物料、多视图、多单 / 跨域引用不增加原不良事实数。不承诺无序列标识时精确去重实物，不冻结后置指标算法。
- G4 安全与一致性：服务端复验权限、版本、幂等及真实状态；并发失败保留输入，不产生部分删改、重复发单或重复关闭。事务、审计、Outbox / Worker 复用现有能力，不以假待办掩盖投影延迟。
- G5 附件：复用受控上传、授权、扫描及版本绑定；图片支持弹窗放大 / 缩放，PDF 受控预览，其他获准文件明确提示并授权下载；不默认支持 Office 在线转换，不泄露临时地址或内部资料。
- G6 表单与提示：不自行增加必填、默认值、审批或自动责任判定；小感叹号配说明浮层，支持键盘聚焦和触屏点击。真正的权限 / 读写失败明确报错，不藏入非阻断提示；既定选填不被完整提交变相强制。

- 规则：原组织结构 / 部门岗位收敛为单一“组织与岗位”入口；左树组织 / 部门 / 科室，右侧基本信息、岗位、人员任职。明确新增部门与新增子组织，部门下新增下级 / 岗位；复用 Organization、Department、Position，不合表、不重建账号管理、不新增主副岗。
- 验收：同一数据源及授权上下文、节点定位 / 岗位过滤、切组织清旧结果、部分权限可见区域、分页及旧定位链接有效，无权组织名称 / 人数不泄露。依赖：G1 / G4、S2；来源：D58～D59，第 9.10 节。
### QMS-DISC-002｜管理员全量适用功能岗位｜已确认｜主要角色：授权管理员、任职用户
- 规则：管理员纳入组织岗位及有效任职链，配置本组织统一目录全部适用功能；不额外创建业务超管旁路，不自动取得其他组织 / 供应商权限，不替代经理 / 部长签批或对应工程师专属动作资格。
- 2026-10-26变更：负责人通过REQ-0030及当前直接开工指令，明确平台管理员可管理公司内部各组织全部适用功能，新内部子组织进入范围、新有效功能受控补齐；采用显式授权并复用岗位/任职和兼容来源，不按用户名判断。普通组织管理员仍按原组织范围，供应商外部身份及业务单据专属职责不因此扩大。该变更覆盖上句对平台管理员“仅本组织”的旧限制，实施/验证与生产授权边界见[REQ-0030修复计划](../plans/2026-10-26-req0030-admin-process-fix.md)。
- 验收：权限目录、授予上限、自锁保护及有效权限预览可核对；旧管理员账号 / 直接兼容授权不自动清空或重复任职，新增权限经目录核查明确配置。依赖：001、G1；来源：D59、S2 第 1.2 节。
### QMS-DISC-003｜名称与代码原地纠错｜已确认｜主要角色：组织 / 部门维护人
- 规则：组织 / 部门 / 科室名称及代码可授权编辑，保留原 UUID、任职及业务关系；组织代码全局唯一、部门代码本组织唯一，保留旧新值及历史展示，不联改岗位 roleCode、权限或发布流程。

### QMS-DISC-004｜误建未用对象受控删除｜已确认｜主要角色：有删除资格的管理员
- 2026-10-28负责人最新修订优先：必须支持管理员强制删除组织；当前配置关联允许自动转空，后续涉及时提示针对性补配，不再要求先手工拆除角色、授权、用户、岗位、日志、技术回执或历史引用。保留业务/审计事实及租户隔离，不做全库级联销毁或把历史归属UUID无差别置空；新技术方案见[REQ0030计划第8节](../plans/2026-10-26-req0030-admin-process-fix.md)，尚未实施/生产执行。下述旧“有引用阻止删除”规则仅代表此前版本，不再作为强制删除功能目标。
