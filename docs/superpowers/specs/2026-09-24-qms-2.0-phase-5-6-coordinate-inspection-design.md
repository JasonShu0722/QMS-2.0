# QMS 2.0 阶段五 5.6 三坐标检测设计规格

- 日期：2026-09-24
- 状态：H5 最小纵向切片设计；只覆盖检测申请、审批、排单和使用进度

## 范围

三坐标检测领域持有检测申请事实、审批结论、排单时间和使用进度。申请关联拥有组织、零件/样品、图号或批次、优先级和期望完成时间；申请提交后不可静默改写关键样品信息。审批、排单和进度变更均保留版本、操作者和审计记录。

本切片不建设仪器台账、校准/计量、MSA、质量成本、完整试验管理，也不直接连接 ERP、MES 或外部检测设备。外部来源字段仅在确认真实契约后另立适配器。

## 状态机

`DRAFT -> SUBMITTED -> APPROVED -> SCHEDULED -> IN_PROGRESS -> COMPLETED`；审批拒绝进入 `REJECTED`，被拒申请可由新版本重新提交。排单只能作用于 `APPROVED`，进度只能作用于 `SCHEDULED` 或 `IN_PROGRESS`。

## 权限和隔离

- `coordinate-inspection:read`：查看本组织申请、排单和进度。
- `coordinate-inspection:write`：创建、提交、更新进度。
- `coordinate-inspection:approve`：审批或拒绝申请。
- `coordinate-inspection:schedule`：安排检测时间和负责人。
- 所有查询按服务端拥有组织过滤；供应商账号不能访问内部检测资源。

## 验收边界

至少验证状态转移、版本竞争、组织隔离、审批/排单权限、重复幂等键、真实 PostgreSQL 迁移和 OpenAPI 契约。对象存储、扫描、Worker 和浏览器联合验收在申请附件接入后另行执行。
