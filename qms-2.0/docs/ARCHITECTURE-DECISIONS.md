## 新决策记录模板

将新决策写入对应规格或独立规格，再在上表登记唯一编号和链接。变更现有决策须保留旧记录，并明确替代关系。

```markdown
## ADR 编号与标题

- 状态：提议 / 已确认 / 已替代
- 日期、负责人及确认依据：
- 问题、业务约束和可验证目标：
- 备选方案与现有能力复用评估：
- 选择与理由：
- 数据、权限、契约、运维影响及代价：
- 验证结果、迁移方案与回退条件：
- 替代的旧决策 / 替代本决策的新记录：
- 重新评估触发条件：
```

不要因依赖版本更新自动推翻决策；先提交[变更影响分析](CHANGE-IMPACT.md)，再更新规格、实现、测试与本索引。
