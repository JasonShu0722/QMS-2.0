# QMS UI 方向样板

本样板已登记为项目的设计参考。后续开发必须遵循[前端统一设计规范](../../../../../../docs/superpowers/specs/2026-09-21-qms-frontend-design-standard.md)；参考代码、样式边界、正式接入顺序和验收见[实施指南](../../../../../docs/FRONTEND-DESIGN.md)。规范要求优先于样板简化行为，不将本目录整份复制或导入正式应用。外观入口统一保留在右上角。

独立的 React + Ant Design 交互样板，验证综合工作台、质量分析中心和 8D 处理空间。布局参考 Sneat 的轻量后台风格；未使用付费素材或套件源码。

从 `qms-2.0/` 运行：

```powershell
node apps/web/node_modules/vite/bin/vite.js apps/web --host 127.0.0.1 --port 18766 --strictPort
```

打开 `http://127.0.0.1:18766/ui-prototype.html`。通过 `?page=workbench`、`?page=analytics`、`?page=workspace` 直达三种页面。

可试用待办筛选、时间/来源切换、缺陷下钻、演示 CSV 导出、流程节点切换、D4 编辑/草稿暂存/提交评审、报告、操作记录和专注模式。其他应用入口说明规划边界。

数据均为演示数据，暂存仅在页面内存中，刷新重置。此入口不接入 API、认证或数据库，也不改变正式路由和全局样式。现有 Vite 生产构建仅包含正式 `index.html` 入口。

## 离线分享

从 `qms-2.0/` 执行：

```powershell
node apps/web/scripts/build-ui-prototype-offline.mjs
```

生成 `dist/share/QMS-UI-Preview.html`（V2 约 750 KiB）。将这一个文件发送给查阅者，用 Chrome / Edge 打开即可。工作台、台账、分析和多个问题工作页、演示数据、React、组件、样式及 SVG 图标均在文件内，无需服务端、CDN 或安装依赖。页面切换使用本地哈希地址，草稿仍只存于内存。分享文件保留演示标识；附件入口不包含真实附件。

## 第二版体验路线

1. 从工作台进入「问题与改进」，查看图标轨与业务菜单。
2. 在台账打开两条记录，查看内部工作标签；重复打开同一记录只激活已有标签。
3. 打开更多记录或缩窄窗口，使用「全部已打开」检索溢出标签；只有一个工作页时不显示标签条，可通过「工作页」管理入口关闭。
4. 在 D4 编辑文字并切换记录，演示草稿保留于内存；未保存时关闭会提示，刷新会重置正文。仅渲染活动页。
5. 顶栏「外观」可选择浅色、深色、跟随系统及蓝、青、紫主色。偏好会记忆，风险与状态色语义固定。
6. 「专注处理」收起领域导航和右侧辅助栏；另开浏览器页签只带当前记录地址，不复制未保存正文。

V2 已通过 Web 类型检查、正式构建与离线构建，并验证 1440 × 1000、390 × 844 下的导航、36 px 单行标签、去重/收纳/关闭/恢复、草稿关闭保护、主题切换及专注模式。非主示例记录主要用于多标签演示。会话存储只保存标签元数据，浏览器存储被禁用时退化为内存使用。系统主题运行时变更和本地 file URL 运行未实测。

导出为独立构建，不修改正式 Web 构建配置。脚本检查单一 JS/CSS 产物及外部引用，生成文件的 CSP 禁止网络连接。2026-09-20 单文件构建、内嵌脚本语法检查及 Web 类型检查通过；内嵌浏览器策略阻止 `file:` URL，因此未完成离线文件的浏览器实测，需接收者在本地浏览器确认。

## 2026-09-20 验证

- `pnpm --filter @qms/web lint`：通过。
- `pnpm --filter @qms/web build`：通过；产物不包含样板 HTML，现有 Ant Design 分包大小警告保留。
- 浏览器：1440 × 1040 桌面和 390 × 844 窄屏布局；三页无整页横向溢出。
- 已验证：待办筛选、分析时间/来源切换、图表下钻、问题跳转、D4 必填校验、保存与提交状态、报告/操作记录、专注模式、移动导航。
- CSV 预览内容可读，可手动选取复制；提供浏览器下载链接，但内嵌浏览器的下载落盘未确认。

这里只验证设计方向与交互，不作为真实业务验收。各指标为独立的布局示例，正式接入需要统一统计口径；D0–D8 为示例流程，不能替代正式动态流程。正式接入前还需完善组件拆分、键盘与辅助技术体验及业务权限状态。
